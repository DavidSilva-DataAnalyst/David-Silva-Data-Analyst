# Venta de Clientes por Departamento — Dashboard Interactivo en Power BI

## Objetivo

Demostrar conocimientos técnicos en **Power BI** mediante la integración de datos provenientes de múltiples orígenes, el establecimiento de relaciones entre diferentes tablas y el uso de **Power Query** para la transformación, limpieza y preparación de la información.

## Datos

El dashboard se encuentra conectado a múltiples archivos de **Excel** que funcionan como fuentes de datos. Cualquier modificación o nuevo registro agregado en estos archivos se refleja automáticamente en el dashboard al actualizar la información, sin necesidad de reconstruir las visualizaciones de forma manual.

## Resultado

Para visualizar el resultado del proyecto, consulte la carpeta de **Capturas**, donde se muestran las principales visualizaciones implementadas. Además, se incluye el archivo de **Power BI (.pbix)** para que pueda explorar el dashboard de manera interactiva.
